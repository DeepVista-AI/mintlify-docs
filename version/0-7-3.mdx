title: "Version 0.7.3"
description: "Live agent actions in floating chat, faster keyboard navigation, draft saving, default trackers in new workbenches, and on-demand version saving."
---

September 3, 2026

#### **1. Watch your agent work from chat history**

The floating chat now shows background actions directly in each thread's preview.

Glance at a thread and see whether the agent is searching the web, updating a card, or running a task, before you even open it.

![A chat thread preview showing an agent's live background actions](/images/release-0-7-3-agent-actions-preview.gif)

#### **2. Jump straight to a result with ⌘K, and save drafts with ⌘S**

Global search now supports full keyboard navigation. Press `⌘K` (or `Ctrl K`) to open search, then use the Up and Down arrow keys to highlight and open notes, databases, and workflows without reaching for your mouse.

![Navigating global search results with arrow keys](/images/release-0-7-3-cmdk-navigation.gif)

Pressing `⌘S` (`Ctrl S`) now saves your active document or note draft immediately, instead of waiting on autosave.

#### **3. New workbenches come with a tracker built in**

Every workbench you create now starts with a default parent tracker. Start researching leads and roll out child trackers as you sort out certain people.

![A new workbench showing a default parent tracker already in place](/images/release-0-7-3-tracker-in-workbenches.gif)

#### **4. Save a version whenever you want**

Notes and context cards now have a "name current version" button. Snapshot your work at any time so that you never lose it.

![The name current version button on a note](/images/release-0-7-3-save-version.png)

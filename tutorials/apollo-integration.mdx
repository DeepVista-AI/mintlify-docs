## Overview

[Customer Research & Tracking](/tutorials/customer-research-and-tracking) already runs deep research to find and qualify leads. Connecting **Apollo** adds a second, verified source: DeepVista can query Apollo's people-search database directly, so your tracker comes back tagged **Apollo Verified**, with each row's `Source` column set to `Apollo`, instead of leads compiled from deep research.

<Note>
  Apollo's direct people-search endpoint requires an **Apollo Master API Key**. A standard API key won't work for this integration — check your Apollo plan supports Master Key access before you start.
</Note>

## Prerequisites

- A DeepVista account with an active project. [Sign up here](https://app.deepvista.ai/login?redirectUrl=%2Fsign%2520in) if you don't have one.
- An [Apollo](https://www.apollo.io) account with a Master API Key. In Apollo, go to **Settings → Integrations → API** to generate one.

## Step-by-step guide

<Steps>
  <Step title='Ask DeepVista: "Help me connect with Apollo integration."'>
    DeepVista returns a **Connect Apollo Integration** link through Composio. This link is valid for 10 minutes.

    <Frame>
      ![DeepVista chat with a Connect Apollo Integration link and next steps for authorizing the connection](/images/apollo-integration-connect-link.png)
    </Frame>
  </Step>

  <Step title="Open the link and authorize with your Apollo Master API Key.">
    Open it in your browser, enter your Apollo API key on the authorization screen, and let DeepVista know once it's done — or just run your search directly.
  </Step>

  <Step title="Test the connection with a real search.">
    Try a prompt like:

    ```text
    Find 20 Seed/Series A B2B SaaS founders in the US.
    ```

    DeepVista returns a tracker sourced directly from Apollo, with every row's `Source` column set to `Apollo`.

    <Frame>
      ![A US B2B SaaS Founders (Apollo Verified) tracker with a Source column set to Apollo on every row](/images/apollo-integration-verified-tracker.png)
    </Frame>
  </Step>
</Steps>

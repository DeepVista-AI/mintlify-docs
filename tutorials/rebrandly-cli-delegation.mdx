## Overview

Integrating the **Rebrandly CLI** with DeepVista lets your workflows create, customize, and manage branded short URLs (e.g. `link.yourdomain.com/xyz`) directly from prompts.

When delegating CLI operations to a local runner, your API key is never passed through chat prompts, uploaded to cloud servers, or stored in DeepVista chat history.

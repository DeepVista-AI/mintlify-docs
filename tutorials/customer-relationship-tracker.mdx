## Overview

Customer relationships tracked across scattered spreadsheets, project tabs, and chat threads fall out of date fast. This tutorial sets up a single customer tracker in DeepVista, where every row is a real account you can update just by chatting.

## Prerequisites

Before you start, make sure you have:

1. A DeepVista account with an active project

## Step-by-step guide

<Steps>
  <Step title="Ask DeepVista to set up your tracker">
    If you already track customers somewhere, describe them in chat, or drop in screenshots of a project list, spreadsheet, or any other format you already have them in:

    ```text
    Here are some customers we have, please help me set up a customer
    tracking system.
    ```

    Starting from scratch? Ask for a blank tracker instead. New leads populate it automatically once you complete Step 2:

    ```text
    Set up a blank customer tracker so I can start capturing leads.
    ```

    DeepVista creates a table card using these columns as the schema:

    <Frame>
      ![DeepVista confirming the Customer CRM Tracker table card was created](/images/image-13.png)
    </Frame>

    | Column | What it tracks |
    |---|---|
    | `stage` | Lead, Discovery, Pilot, Active, Expanded, or Churned |
    | `priority` | Urgent, High, Medium, or Low |
    | `contact_person` / `contact_email` / `domain` | Who you talk to, and where |
    | `arr_mrr` | Recurring revenue commitment |
    | `health_score` | High, Medium, or Low |
    | `next_action` | The next thing to do for this account |

    Every row in your tracker is a real organization or person card in VistaBase, so updating a row updates that account everywhere in your workspace.
  </Step>
</Steps>

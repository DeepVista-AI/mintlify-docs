## Overview

By the end, you'll know when a dedicated private server is the right choice and how to request one.

For production workloads, complex automations, or always-on agents, keeping a personal laptop awake is often impractical. DeepVista can provision a fully managed private server that runs in the cloud around the clock.

<Note>
  This is an alternative to [Connect your machine](/tutorials/server/local), not a follow-on step — pick whichever fits your workload. You don't need both.
</Note>

<Frame>
  ![Dedicated private server option in DeepVista](/images/serv-1.png)

## When to choose a private server

Choose a private server if you need:

- Workflows that must stay online overnight or while your laptop sleeps
- A dedicated environment for team or production automations
- Managed hosting instead of operating your own always-on machine

Stay on a local machine if you're prototyping, testing Deep Workflows, or only need the runner during the workday.

## Step-by-step guide

<Steps>
  <Step title="Request a private server">
    Email [support@deepvista.ai](mailto:support@deepvista.ai) to request a managed instance. Include a short description of your workload and expected uptime.

    The DeepVista team will follow up on requirements, capacity, and pricing. After provisioning, the instance appears under **Private server** in your dashboard.
  </Step>
  <Step title="Authorize with Claude Code">
    Once the private server is active, authenticate it with Claude the same way you would any connected machine. Use the tutorial below for the full walkthrough.
  </Step>
</Steps>

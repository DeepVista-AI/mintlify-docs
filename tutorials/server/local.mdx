</Note>

## Before You Begin

<Warning>
  **Important Requirement:** Remote workflows will only execute as long as your connected machine is active, awake, and online. If your machine goes to sleep, shuts down, or loses its internet connection, the DeepVista runner will go offline and pending tasks will queue until it reconnects.
</Warning>

## Step-by-step guide

<Steps>
  <Step title="Open your machine's terminal from DeepVista">
    Go to **Settings → Machines**, then under **Connect your machine**, click **Open Terminal**.

    <Frame>
      ![Settings > Machines page with the Open Terminal button highlighted](/images/connect-your-machine/settings-machines-open-terminal.png)
    </Frame>
  </Step>
  <Step title="Copy, paste, and run">
    Copy the command shown, paste it into your terminal, and hit **Return**.
  </Step>
  <Step title="Let the setup checklist finish">
    The command installs the DeepVista CLI and Claude Code (skipping anything already installed), then starts listening for tasks.

    <Frame>
      ![Terminal running the quickstart command, checking off already-installed dependencies before starting the task daemon](/images/connect-your-machine/quickstart-terminal-checklist.png)
    </Frame>

    Already completed [Mac Setup](/tutorials/mac-setup)? Most items will already be checked.
  </Step>
  <Step title="Confirm your machine is online">
    Back in DeepVista, your machine now appears under **Connected machines** with a green dot, ready to receive work.

    <Frame>
      ![Connected machines list showing a machine online with a green status dot](/images/connect-your-machine/machine-connected-online.png)
    </Frame>
  </Step>
  <Step title="Run a test task">
    Click the send icon next to your machine to send a test task.

    <Frame>
      ![Send test task button next to a connected machine](/images/connect-your-machine/send-test-task-button.png)
    </Frame>

    DeepVista reports back your machine's disk usage and configured connectors, confirming everything is wired up correctly.

    <Frame>
      ![DeepVista chat showing a completed test task with disk usage and connector details](/images/connect-your-machine.gif)
    </Frame>
  </Step>
</Steps>

Once the test task completes, you're ready to run a Deep Workflow.

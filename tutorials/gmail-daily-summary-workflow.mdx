## Overview

DeepVista can sync your Gmail into memory and, on request, compose and send a daily summary email pulling from your notes, syncs, and recent activity. This tutorial walks through connecting Gmail from Settings and asking DeepVista to send a daily summary, one example of the kind of Gmail task you can hand off once it's connected.

## Prerequisites

Before you start, make sure you have:

1. A DeepVista account with an active project
2. Access to the Gmail account you want to connect
3. Some existing notes or memory entries you'd like summarized (e.g. daily planning notes, sync recaps)

## Step-by-step guide

<Steps>
  <Step title="Open Account and Settings">
    Click user, then select **\+ Gmail**.

    <Frame>
      ![Settings page with the User menu open, showing the Gmail data connector](/images/image-1.png)
    </Frame>
  </Step>
  <Step title="Grant access">
    Make sure DeepVista has the following access.

    <Frame>
      ![Google OAuth consent screen showing the Gmail permissions DeepVista requests](/images/image-2.png)
    </Frame>
  </Step>
  <Step title="Get redirected to the homepage">
    Upon success, you'll see this page and get redirected to the home page automatically.

    <Frame>
      ![Confirmation screen after Gmail is successfully connected](/images/image-3.png)
    </Frame>
  </Step>
  <Step title="Ask DeepVista for a daily summary">
    In chat, ask for a summary and name the recipient:

    ```text wrap
    Can you list my emails in the last day and create an overall summary and send it to me. Schedule a job to do it daily
    ```

    <Frame>
      ![Image](/images/image-14.png "Image")
    </Frame>

    <Frame>
      ![Image](/images/image-15.png "Image")
    </Frame>

    DeepVista searches your memory and notes for relevant context — recent syncs, daily planning entries, and anything tied to the recipient.

    <Tip>
      The more specific your notes are (dated planning entries, sync recaps, named follow-ups), the more useful the generated summary will be. DeepVista pulls directly from what's already in memory.
    </Tip>
  </Step>
  <Step title="Check the delivered email">
    The recipient receives a formatted summary email — in this example, "DeepVista Daily Progress & Sync Summary" for the day, recapping feedback, decisions, and an agenda for the next sync.

    <Frame>
    </Frame>
  </Step>
</Steps>
